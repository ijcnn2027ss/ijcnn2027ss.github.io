<h1 align="center">SPECIAL SESSION PROPOSAL</h1>

## Knowledge-Enhanced AI for Real-World Applications

This repository hosts the website of the proposed special session at the International Joint Conference on Neural Networks (IJCNN 2027).

### Conference Information

- **Conference:** International Joint Conference on Neural Networks (IJCNN 2027)
- **Date:** June 14–18, 2027
- **Location:** Cape Town, South Africa

### Special Session Overview

Neural networks increasingly support decisions in settings where relevant knowledge is scattered across documents, images, sensor streams, and domain rules.

This special session explores how neural models can use, integrate, and update domain knowledge while maintaining reliability when evidence is incomplete, noisy, or changing.
